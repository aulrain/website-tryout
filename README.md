# Portfolio Website

A futuristic Apple-style portfolio website with smooth animations and deep blue, black, and white gradients.

## Features

- **Modern Apple-style Design**: Clean, minimalist interface with elegant typography
- **Deep Blue/Black/White Color Scheme**: Professional gradient backgrounds
- **Smooth Animations**: Scroll-triggered animations and interactive hover effects
- **Responsive Layout**: Works perfectly on all devices
- **5 Main Sections**:
  - Home (Hero intro with animated title)
  - About (Short bio with skill tags)
  - My Works (Gallery with hover effects)
  - Motion Edits (Animated carousel)
  - Contact (Working contact form)

## How to View

Simply open `index.html` in any modern web browser, or use a local server:

```bash
# Using Python
python3 -m http.server 8000

# Using Node.js
npx serve

# Then open http://localhost:8000 in your browser
```

## Technologies Used

- HTML5
- CSS3 (with gradients, animations, and responsive design)
- Vanilla JavaScript (Intersection Observer API for scroll animations)
- No external dependencies required!
